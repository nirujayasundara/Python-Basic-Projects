# Python Fundamentals — Data Technician Bootcamp Project

## Overview

This project was completed as part of **Data Technician Bootcamp — Week 6: Python Fundamentals**. The week focused on building core programming logic in Python through a series of guided exercises and mini projects, run in Google Colab notebooks. The work progressed from basic syntax and user interaction through to small self contained programs that combine multiple concepts, culminating in an interactive **ATM simulator**.


## Tools & Environment

- **Language:** Python 3
- **Environment:** Google Colab (Jupyter notebooks)
- **Practice platforms:** HackerRank, CodeChef (additional coding challenge practice)


## Skills Demonstrated

### Variables & Data Types
- Declaring and using variables to store user input, calculation results, and program state
- Working with different data types (strings, integers, floats) and converting between them with **type casting** (`int()`, `float()`, `str()`)  for example, converting user entered temperatures, ages, and monetary amounts into the correct numeric type for calculations

### `print()`
- Using `print()` to display formatted output, results, and menus to the user
- to build interactive, conversational command line programs  e.g. taking a user's name and age and returning a personalised greeting

### `if` Statements & Conditional Logic
- Using `if` / `elif` / `else` to branch program behaviour based on conditions
- Validating user input and responding appropriately (e.g. checking a number is even or odd, positive/negative/zero, or a valid ATM menu option)
- Building multi-level conditional logic, such as checking whether a withdrawal amount is a valid multiple of 10 and within the allowed balance before processing it

### `for` and `while` Loops
- Using `for` loops to iterate over ranges and lists for example, looping through integers 1–100 to solve the classic **FizzBuzz** problem, and printing the first 10 even numbers
- Using `while` loops to keep a program running until a specific condition is met, such as repeatedly showing an ATM menu until the user chooses to exit
- Combining loops with conditionals to solve list-based problems, such as finding the maximum/minimum value in a list or summing all positive numbers

### Building Logic, Performing Calculations & User Interaction
- Combining variables, input/output, type casting, conditionals, and loops into complete working programs, including:
  - **FizzBuzz** looping 1 to 100, using modulo division and `if`/`elif`/`else` to print "fizz", "buzz", "fizzbuzz", or the number itself
  - **ATM Simulator**  a menu-driven program using functions for each operation (check balance, deposit, withdraw, exit), `while` loops to keep the menu running, and `if` statements to validate withdrawal amounts and PIN entry
  - **Calculators & converters**  sum of two numbers, Celsius to Fahrenheit conversion, rectangle area, compound interest, and days-to-years/weeks/days conversion
  - **Text & number analysis** word counting in a sentence, digit-sum calculation, palindrome checking, prime number checking, and leap year checking


## Key Takeaway

This project built confidence in core Python building blocks variables, I/O, type casting, conditionals, and loops  and demonstrated how these fundamentals combine to create working, interactive programs. The ATM simulator in particular tied everything together: user input and validation, menu-driven control flow with loops, conditional branching for business rules, and functions to keep the logic organised  a solid foundation for tackling more advanced data analysis work in Python (Pandas, data visualisation) covered later in the bootcamp.
